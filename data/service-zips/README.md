# Service-area zip lists

`hou_wsnc_default.csv` holds the **temporary** default zips for Houston (HOU) and Winston-Salem
(WSNC). sql/141 loads them. They stand in until Mark uploads each market's real list, which then
replaces them through `scripts/import-service-zips.js --replace`.

- **Generated by** `scripts/build-default-service-zips.js`. Never edit by hand.
- **County:** taken from the US Census Bureau 2020 ZCTA↔county relationship file. When a zip
  crosses county lines, it goes to the county that holds the largest share of its land.
- **City:** taken from the GeoNames US postal codes file (https://www.geonames.org), licensed
  CC BY 4.0.
- **Known gap:** zips used only for PO boxes are not in the Census file, so this list leaves them
  out.
