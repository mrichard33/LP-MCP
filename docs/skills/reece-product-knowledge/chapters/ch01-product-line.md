# Chapter 1: Conservation Windows Product Line & Decorative Options

**Source:** *Conservation Windows* brochure (manufacturer collateral, Conservation Windows by Regency Plus Inc.)

**Scope:** covers the Regency Plus Conservation window line and sliding patio door only. Other doors (fiberglass/steel entry, other brands) and roofing are NOT covered here — don't assume Conservation specs apply to them. Attribute superlatives ("guaranteed highest R value," "best guarantee in the industry," "America's Most Trusted Name") to the manufacturer; never state them in Randy's voice as Reece's own claim.

## Core Idea
Conservation Windows is a custom-made vinyl replacement line sold by Reece Windows & Doors in seven product families **in this brochure**, all glazed with Hi-Performance Conservation Glass. The count describes the brochure, NOT everything Reece sells — **single-hung is also offered** (owner ruling, ch08) and is absent from these four PDFs. Match the style to the home's architecture and the opening's constraints (walkways, sinks, views), then pick color, grids and glass.

## Frameworks Introduced
- **Style-to-situation matching** (how the brochure positions each family):
  - When to use: choosing or recommending a window type.
  - How: Traditional architecture → Double-Hung, or Single-Hung where only the bottom sash needs to open (offered per ch08; the brochure does not position it). Opening faces a walkway/patio/deck where a projecting sash would interfere → Slider. Modern design, max view + airflow → Casement/Awning. Traditional or Victorian, want openness → Bay/Bow. Over a kitchen sink or in a bathroom → Garden Window. Wall-to-wall glass entry → Sliding Patio Door.
- **Common spine**: every family = Hi-Performance Conservation Glass + extruded aluminum screen frame (except Bay/Bow and Garden, which list different build details) + "Florida approved" (stated for Double-Hung, Slider, Casement/Awning).

## Key Concepts
- **Tilt-in sash**: sash swings into the room so the exterior glass can be cleaned from inside.
- **Coved glazing bead**: interior trim holding the glass; a beauty feature in this line.
- **Constant force balance**: spring system holding a hung sash at any height.
- **Night latch (ventilation latch)**: lets a sash lock partly open for secure airflow.
- **Multi-point lock**: locks at several points along the sash — casement/garden security.
- **Florida approved**: product carries Florida approval (brochure claim; no approval numbers given).

## Mental Models
- Think of the product line as **one glass package in seven frames** — the energy story (ch02) applies to every style. "Seven" is this brochure's count, not the catalogue's (single-hung, ch08).
- Use operation type as the first filter (hung — double or single — / slide / crank-out / fixed / projecting), then architecture, then options.

## Anti-patterns
- **Assuming every family is "Florida approved"**: the brochure states it only for Double-Hung, Slider and Casement/Awning.
- **Saying grids must be cleaned around**: grids sit between the panes.
- **Quoting product-approval numbers**: none appear in these sources.
- **Applying Conservation specs to entry doors, other brands or roofing**: out of scope for this skill.

## Key Takeaways
1. Seven families **in this brochure**: Double-Hung, Slider/Tilt-In Slider, Casement & Awning, Bay & Bow, Garden, Sliding Patio Door (+ Picture, Round Top, Hopper, Trapezoids per features chart). **Single-hung is also offered** and is not in these docs — ch08.
2. All use Hi-Performance Conservation Glass.
3. Five frame color schemes, three grid colors, four grid patterns, grids inside the glass.
4. Sliders solve walkway/deck clearance; casements maximize view & airflow; garden windows for sink/bath.
