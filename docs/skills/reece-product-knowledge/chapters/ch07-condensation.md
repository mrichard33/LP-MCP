# Chapter 7: Condensation — Causes, Fixes & When to Worry

**Source:** *Care & Maintenance Instructions* (Condensation section), ©2024 Reece Windows & Doors; warranty IG condensation clause

## Core Idea
**Faulty windows do not cause condensation — indoor humidity does.** New, tight windows stop the drafts that used to carry moisture out, so condensation may appear more often after replacement. Only condensation *between* the panes signals a window problem.

## Frameworks Introduced
- **"Are my windows to blame?" → No.** Glass is simply the coldest surface in the house, so moisture shows there first.
- **Where is the moisture? (diagnostic)**:
  - **Inside room-side surface** → indoor humidity; control humidity.
  - **Outside surface** → temperature differential; normal (the "bathroom mirror" effect).
  - **Between the two panes** → airtight seal has failed; glass needs replacing (IG warranty issue).
  - **Walls/ceilings/wood/plywood damage, mold** → serious indoor moisture problem; call a heating & cooling contractor.
- **Seasonal pattern**: new/remodeled homes and summer-humid houses hold moisture; condensation appears when heating starts in early winter and eases after a few weeks as the house dries out.

## Reference Tables

### Ways to reduce condensation
| Action |
|---|
| Open a window briefly (quick temporary fix) |
| Crack a window or door open daily |
| Run exhaust fans longer in kitchen, bathroom, laundry room |
| Open drapes and blinds so air circulates |
| Turn off humidifying devices |
| Install and use a dehumidifier |
| (Implied) Vent clothes dryers outside |

### Moisture sources named
Showers · cooking · clothes dryers not vented outside · building materials in new/remodeled construction · humid summer air absorbed by the house.

## Key Concepts
- **Condensation**: water or frost formed when warm moist air meets a cooler surface.
- **Relative indoor humidity**: the real cause; high RH + cold glass = condensation.
- **Seal failure**: loss of the insulated unit's airtight seal → fog between panes.
- **Air exchange**: older drafty windows leaked moist air out; efficient windows don't.

## Mental Models
- Think of condensation as a **humidity gauge**, not a window defect — it proves the house is tighter.
- Use the "bathroom mirror" analogy for homeowners; it lands instantly.
- **Between-the-glass = our problem; room-side = the home's humidity.**

## Anti-patterns
- **Promising new windows will eliminate condensation**: they can increase visible condensation. (Warmer glass — ch02 — helps, but doesn't eliminate it.)
- **Treating room-side condensation as a warranty claim**: the IG warranty explicitly excludes temporary condensation and pre-existing condensation conditions.
- **Ignoring structural signs** (peeling paint, rot, mold): route to an HVAC contractor.

## Worked Example
Customer, three weeks after install in November: "My new windows are sweating — are they defective?"
1. Ask where: inside surface → humidity, not the window.
2. Explain: old windows were drafty and let moisture escape; new windows seal it in. Glass is the coldest surface, so it shows first.
3. Timing: common when heating starts; usually eases in a few weeks.
4. Fixes: run bath/kitchen fans longer, open blinds, turn off humidifiers, consider a dehumidifier.
5. Escalate only if fog is **between the panes** (seal failure → IG warranty claim, ch05) or walls/ceilings show moisture damage (HVAC contractor).

## Key Takeaways
1. Windows don't cause condensation; humidity does.
2. Tighter new windows can show more condensation because drafts no longer vent moisture.
3. Fog between panes = seal failure = IG warranty territory.
4. Reduce with ventilation, fans, open blinds, no humidifiers, dehumidifier.
5. Moisture damage on walls/ceilings → heating & cooling contractor.
