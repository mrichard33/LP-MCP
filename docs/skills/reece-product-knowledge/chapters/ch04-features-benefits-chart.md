# Chapter 4: The 33-Point Features & Benefits Chart

**Source:** Reece Windows & Doors "Feature / Benefit" chart (in *Conservation Windows Warranty Information* and pages 7–8 of *Conservation Windows Double Lifetime Warranty*)

## Core Idea
The chart is the manufacturer's official like-for-like spec list (it also backs the old-brochure 30-Day Price Guarantee, which is unconfirmed — don't use; see ch05). It is also the most compact feature→benefit source for sales conversations.

## Frameworks Introduced
- **Feature → Benefit pairing**: every construction detail is stated with the homeowner outcome it produces. Use the same pairing when explaining any item.
- **Like-for-like benchmark**: the chart defines what "comparable window" means when comparing competitor specs.

## Key Concepts
- **STC (Sound Transmission Class)**: sound-blocking rating; 46 claimed via double tempered glass.
- **Annealed glass**: standard untempered glass; the upgrade replaces 1/8" annealed.
- **Warm-edge spacer**: low-conductivity spacer between panes that cuts edge condensation.
- **Fusion-welded miter**: corners melted together rather than mechanically joined.
- **Muntins / grids**: decorative bars dividing the glass.

## Mental Models
- Use the chart as a **competitor checklist**: a "cheaper equivalent" quote is only equivalent if it matches every line.
- Think of items 26–27 as the bridge between product and warranty: the "Double Lifetime" = frame (vinyl) + glass.

## Anti-patterns
- **Paraphrasing the claims loosely**: "3× stronger than aluminum," "equal to 5 panes," "guaranteed highest R value," "50% quieter," "99% UV," "best guarantee in the industry," "virtually stops glass breakage" are manufacturer-documented and approved as product facts. Quote them as written; don't inflate (e.g. "unbreakable"). Attribute the superlatives ("guaranteed highest R value," "best guarantee in the industry") to the manufacturer, never to Randy/Reece.
- **Using "air filtration"**: the chart's wording; the correct term is air *infiltration*.

## Key Takeaways
1. 33 features define "like-for-like" for spec comparisons (the 30-Day Price Guarantee tied to it is unconfirmed — don't use).
2. Frame: CPE/TiO₂-modified PVC, metal-alloy reinforced, honeycomb, fusion-welded.
3. Glass: laminated exterior, intrahesive + drop-in glazing, warm edge, STC 46, UV protection.
4. Security: Entry-Guard locks; double locks over 20" wide; interlocking meeting rails.
5. Every chart claim is manufacturer-documented and approved; quote it as written.
